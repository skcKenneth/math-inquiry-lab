# 設計規格｜少裝飾，多證據

## 1. 這個網站是甚麼

個人中學數學探究教具，不是求職廣告、科研展示或大型學習管理系統。
主語是「學生怎樣理解」，而不是「教師會多少技術」。首頁一句主題，接三個活動；
一個活動頁只處理一個主要概念，用相同流程減少重新學習介面的負擔。

教師透過學生的預測、比較與解釋選擇下一個問題，不以完成按鈕代替學習證據。
這是設計意圖，不是已證實的學習效果。

## 2. 視覺規範

| Token | 值／原則 |
|---|---|
| 背景 | #fafaf7，接近白色的紙感，不能變成奶油色宣傳頁 |
| 操作面 | #ffffff |
| 文字 | #222d29 |
| 次要文字 | #59655e；不為極簡而降低至看不清 |
| 唯一強調色 | #315a49；重點操作與目前曲線 |
| 分隔線 | #d6ddd6 |
| 基本文字 | 16px、行距 1.75；正文用系統 sans-serif |
| 大標題 | 本機 serif fallback；不下載網絡字型 |
| 內容寬 | 1160px；投影模式可到 1440px |
| 互動按鈕 | 至少 44px 高；圓角 3px，沒有陰影 |
| 圖像 | SVG；實線／虛線／不同點形狀，不只靠顏色辨認 |

不要加：玻璃效果、漸層、深色巨幅 hero、滿版裝飾插畫、圓角卡片牆、動畫計數、
學生成績 dashboard、老師肖像、學校校徽、裝飾性 mathematical wallpaper。

## 3. 資訊層次

### 首頁
窄頁首「探究活動／教師手冊／關於」。
主題「讓學生把『會做』變成『說得明』」。
三列活動，各列只有標題、核心問題、建議先備程度及時間、入口。
不放 CV、獎項與論文名單。

### 活動頁（桌面）
```
活動標題＋一個核心問題             本活動教師提示
核心 / 深究 / 挑戰                 投影 / 分享設定
----------------------------------------------------
問題與預測（約 30%）     圖像＋目前設定（約 70%）
控制條件                 數值核對（按需展開）
----------------------------------------------------
記錄目前結果 → 比較紀錄
我的解釋                  離堂題
本機儲存選項              匯出／列印
```

手機改單欄：任務、預測、圖像、控制、補充數值、紀錄。
圖像在操作區內 sticky；操作時仍看得到改變。手機圖像刻度字體相應放大。
教師投影模式只改視覺，不刪筆記，也不是 access-controlled teacher mode。

## 4. 教學流程及分層

「預測 → 操作 → 記錄 → 解釋 → 離堂題」。不強迫先填完才能操作；
學生可以口頭預測，教師可投影使用。同一活動的筆記跨層級保留，紀錄標明層級。
不把「核心／深究／挑戰」寫成弱生／普通／尖子標籤。

具體題目及參考推理唯一來源是 `site/teacher-guide.html` 和各活動的 `.task`。
改動學習目標時，問題、離堂題、程式數值及測試必須一起核對。

## 5. 三個活動的不可省略項

- 二次函數：固定等比例座標刻度；比較線可關；頂點提示先隱藏；a=0 正確處理；
  h 與符號的關係從平方項說明；不得自動改縮放造成伸縮錯覺。
- 概率：正面概率可不是 0.5；多條可重現序列；改 p 或 seed 重設樣本但保留筆記；
  不強制「更接近」；n=0 顯示未定義比例；批次總上限 20,000；抽樣繪圖需說明。
- 迴歸：基準八點不動，只移動新增點；可排除該點比較；固定刻度；滑桿／數字輸入
  是拖曳替代；R² 不代表因果；高槓桿不必然是高影響。

## 6. 狀態與資料

視覺 state 和學生筆記分開。重設圖像只改 state。
本機 storage key：`math-inquiry-lab:v1:<lab>`；預設不用。
僅 share a/h/k 或 p/seed/n/paths 或 rx/ry/included 與 level；不 share free text。
學生檔案匯出不是提交，不存在伺服器端作業收集。
跨分頁持久儲存若被禁止，顯示提示並仍可匯出，不阻止活動。
教師筆記及答案全公開；不能冒稱答案有防護。

## 7. 尚未做的事

不加入登入、課堂管理、AI chatbot、自動評分、PWA service worker、英文全站翻譯、
十多個新活動或 GitHub Issue 作為學生回收機制。先試教三個現有模組中的一個。
新增功能要能清楚回答：它改善哪一個具體教學動作？

## 8. 圖像與風格參考

`docs/previews/` 是由本專案程式在受限、無網絡 DOM 渲染環境截出的畫面；
不是已部署網站的證據。保持此方向，修正實際使用問題而不是重新設計整套 UI。
